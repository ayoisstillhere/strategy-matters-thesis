# /pilots — Early Feasibility & Pilot Tests

This folder contains all preliminary tests run before the full experiment to validate the system design.

**Will contain:**
- `feasibility/` — Early 2-agent debate scripts (pre-implementation, per supervisor's recommendation to validate argumentation evolution over rounds)
- `model_comparison/` — Candidate model comparison results (GPT-4o-mini vs Mistral-7B vs Llama-4-8B for agents; Llama-3-70B vs Mixtral vs GPT-4o for judge)
- `prompt_refinement/` — Iterative prompt testing outputs (persona consistency, moderator quality, framing prompt validation)
- `trigger_calibration/` — Trigger threshold tuning data
- `cross_lingual/` — German vs English pilot comparison (document-grounding divergence)
- `judge_reliability/` — Intra-judge consistency tests (per-dimension Krippendorff's α)
- Feasibility report sent to supervisor
